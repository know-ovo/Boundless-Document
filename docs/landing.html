核心能力

在 Markdown 里直接看到数据、运行代码、操纵 3D。

实时数据展示

通过 live-data 代码块接入 HTTP polling、SSE、WebSocket，在文档中原位渲染动态数据面板，无需切换工具。

可执行代码块

run-js 代码块在 Web Worker 沙箱中安全执行 JavaScript，输出结果直接呈现在代码块下方。计划接入 Pyodide 以支持 Python。

3D 模型与多模态

model3d 块展示 GLB/glTF 模型，asset 块嵌入图片、视频、音频、PDF——所有内容都在文档内直接渲染。

工作方式

源码即文档，预览即应用。

保持纯文本

所有增强块在源码中以 ``` 代码块形式存储，任何 Markdown 编辑器都能打开。没有专有格式，没有锁定。

原地增强

增强块在文档原位置渲染，不弹出面板、不跳转页面。就像 Markdown 图片——写时是配置，看时是内容。

安全沙箱

代码执行和数据访问在隔离的 Web Worker / iframe 中完成，不影响宿主页面。本地文件不掉落云端。

架构

模块化设计，按需组合。

editor

基于 Milkdown 的 WYSIWYG Markdown 编辑器，支持源码 / 预览双模式切换。

blocks

增强块渲染组件：实时数据面板、代码执行结果、3D 模型、多媒体资源。

runtime

数据订阅引擎 + Web Worker 代码沙箱，隔离执行，安全可控。

shared

共享类型定义、Markdown 块解析器、扩展接口——所有包的契约层。
