# 无界文档 - 前端 UI 重构设计方案 (极简现代风)

## 1. 设计目标与视觉基调
当前界面过于原生和简陋。本次重构的目标是将“无界文档”的桌面端应用转变为一个**极简、现代、专注于内容创作**的写作环境。

*   **极简主义 (Minimalism)**：大面积留白，去除生硬的边界线和视觉噪点。
*   **沉浸感 (Immersive)**：UI 元素尽量克制，让用户的注意力回归到文本本身。
*   **温润底色 (Warm Base)**：放弃刺眼的纯白背景，采用偏暖的**米色 (Beige/Off-white)** 作为浅色模式的主背景色，降低长时间写作的视觉疲劳。

## 2. 核心布局架构 (Layout Architecture)
整体采用 `Flex` 布局，分为顶部控制栏、左侧边栏（可折叠）和主编辑区。

### 2.1 顶部栏 (Top Bar)
*   **视觉弱化**：取消底部实线边框，仅通过极淡的阴影或背景色微差与编辑区区分。
*   **左侧区域**：
    *   侧边栏切换按钮 (Toggle)。
    *   Logo (以更精简的字形或图标展示)。
    *   文档标题 (浅色/弱化显示)。
*   **右侧区域**：
    *   文件操作按钮：幽灵按钮 (Ghost Buttons)，悬停时显现，包含“打开”、“保存”。
    *   快捷切换：主题模式切换 (🌗)。
    *   设置入口：⚙️ 图标按钮。

### 2.2 侧边栏 (Sidebar)
*   **交互机制**：通过左上角按钮控制展开/折叠。折叠时完全隐藏，实现无边框沉浸模式。
*   **视觉层级**：使用比主背景稍深的颜色（或微弱的右边框）与主编辑区形成层次。
*   *(注：本次 UI 重构暂不实现侧边栏内部的文件树功能，仅提供视觉骨架和折叠交互状态。)*

### 2.3 主编辑区 (Editor Area)
*   **背景色**：柔和的米色系 (例如 `#FAFAF8` 或 `var(--mantine-color-orange-0)` 等暖色调替代纯白)。
*   **内容居中**：在桌面端大屏幕下，文本内容限制最大宽度（如 `800px`），并水平居中，提供类似纸张的阅读体验。

## 3. 个性化设置系统 (Customization System)
在保持界面克制的同时，提供充分的自定义能力。通过点击右上角的设置图标唤起**设置模态框 (Settings Modal)**。

### 3.1 主题设置 (Theme)
*   支持浅色 (Light，主色调米色) 和深色 (Dark) 模式的完整适配。
*   除了顶部栏的快捷键，设置中也可配置。

### 3.2 强调色 (Accent Color)
*   允许用户将系统默认的品牌色（如 Indigo）替换为预设的其他颜色（如翠绿、暖橙、珊瑚红等）。
*   该颜色将应用于：聚焦的光标、选中的文本背景微光、激活的按钮等。

### 3.3 排版与版式 (Typography & Layout)
*   **字体风格**：提供“无衬线体 (Sans-serif, 现代/清晰)”和“衬线体 (Serif, 传统/阅读)”的切换。
*   **页面宽度**：提供“标准居中 (Standard)”和“宽屏模式 (Full width)”的切换。

## 4. 技术栈考量 (Mantine UI 整合)
目前项目已使用 React + Mantine UI。重构将深度利用 Mantine 提供的功能：
*   使用 `<AppShell>` 组件重构基础骨架，原生支持侧边栏(Navbar)和头部(Header)的管理。
*   使用 `MantineProvider` 的 `theme` 扩展来实现米色背景、自定义强调色和字体的动态切换。
*   使用 `ActionIcon` 和幽灵按钮变体来实现轻量级的交互体验。
