# 扩展边界

这个 Demo 把能力拆成可复用包，避免以后做 Web 版或插件版时重写核心逻辑。

## 包边界

- `apps/desktop`：Tauri 宿主，负责窗口、本地文件、打包和系统权限。
- `packages/editor`：Markdown 编辑器封装，目前提供 Milkdown 和源码模式。
- `packages/blocks`：增强块渲染，包括实时数据、代码执行、3D 和多媒体。
- `packages/runtime`：运行时能力，包括数据订阅和代码沙箱。
- `packages/shared`：文档类型、frontmatter 和 fenced block 解析。

## 后续协作

协作层建议接入 Yjs。编辑器内部状态和增强块配置可以映射为 CRDT 文档，本地持久化优先用 IndexedDB，服务端同步可以选 Hocuspocus 或 y-websocket。

## 后续 AI

AI 层不应直接耦合编辑器。建议新增 `packages/ai`，负责文档切分、嵌入索引、问答引用和摘要。代码执行、网络请求和文件读取都需要单独权限。

## 后续 Web 与插件

Web 版可以直接复用 `packages/editor`、`packages/blocks`、`packages/runtime`。VS Code/Cursor/Obsidian 插件可以先复用块解析和预览面板，后续再接入完整编辑能力。
