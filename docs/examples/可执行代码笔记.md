# 可执行代码笔记

`run-js` 块会在 Web Worker 里执行，避免阻塞主界面。第一版只开放浏览器沙箱里的 JavaScript。

```run-js
console.log("开始计算")
const values = [12, 28, 31, 42]
const total = values.reduce((sum, value) => sum + value, 0)
return {
  values,
  total,
  average: total / values.length
}
```

如果代码报错，错误会显示在当前代码块组件里，不会让整个应用崩溃。

```run-js
throw new Error("这是一条演示错误")
```
