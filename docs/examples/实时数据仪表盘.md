# 实时数据仪表盘

这个示例展示 `live-data` 块。它会定时请求 GitHub API，并在正文位置渲染成实时数据组件。

```live-data
source: https://api.github.com/repos/observablehq/plot
mode: polling
interval: 15000
view: json
```

下面是图表模式，数据来自 Vega 示例数据集。

```live-data
source: https://raw.githubusercontent.com/vega/vega-datasets/main/data/stocks.json
mode: polling
interval: 30000
view: line
x: date
y: price
```
